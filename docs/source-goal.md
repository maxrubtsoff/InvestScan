# Цель: регулярные данные Авито, Циан и Домклика

## Критерий выполнения

Источник считается подключённым только после успешного ежедневного запуска в GitHub Actions: объявления действительно получены, география и арендные поля проверены, источник и время сохранены, ошибки не удаляют прежний каталог. Установка библиотеки или статический снимок не считаются регулярным сбором. ИИ не участвует в сборе, извлечении полей или финансовых расчётах.

## Текущее состояние

- Авито: совместимость с XLSX/CSV/JSON Duff89 реализована. Публичные запросы в среде проекта возвращали недоступность/404. Работающий регулярный поиск чужих коммерческих объявлений не подтверждён.
- Циан: коммерческий адаптер публичного HTML написан и проверен на полученных страницах. Из GitHub Actions приходила защитная страница. Опубликованный снимок датирован и не выдаётся за автоматически обновляемый источник.
- Домклик: обычная публичная страница вернула HTTP 401 с защитной проверкой. Исходный предложенный проект использует приватный API мобильного приложения; подписи и обход TLS не используются.

## Дополнительные проверенные направления

1. https://github.com/MissiaL/avito-api — изучены README и раздел item. Это справочник официального Business API: управление опубликованными объявлениями, статистика и услуги владельца аккаунта. Раздел item не предоставляет подтверждённый поиск всех чужих предложений рынка. Наличие OAuth-ключа само по себе задачу не решает; запрос новых полномочий без подходящего endpoint не обоснован.
2. https://github.com/Ho1ocron/parses-domclick — изучены README, browser.py и parser.py. Альтернативная реализация использует Selenium, сессию браузера и служебный web API. Это не доказательство стабильного или открытого доступа из нашей инфраструктуры; обход текущей защитной проверки не подключён.
3. Подключённый каталог плагинов проверен: подходящий коннектор для Авито/Циан/Домклика не найден. Нерелевантные приложения не предлагаются.

## Следующие допустимые пути

- Проверенный официальный/партнёрский канал чтения рыночных объявлений с документированными правами и географией, если площадка предоставляет такой доступ.
- Разрешённые выгрузки владельцев/агентств, сохраняющие исходные ссылки площадок и время получения. Это обозначается как фид/выгрузка, не как прямой парсинг всей площадки.
- Обычная обработка открытых страниц, если доступ существует без защитной проверки. Изменение разметки устраняется адаптером и тестами, а не выдуманными данными.

Платные сервисы и новые аккаунты без согласования не подключаются. CAPTCHA, авторизация, защитные блокировки и приватные подписи запросов не обходятся. Цель пока не выполнена для всех трёх площадок.
