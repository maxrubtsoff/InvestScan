# Запрос поставщику данных

Статус: проект письма; не отправлено. Регистрация, покупка и договор не совершались.

Адресат: info@metrapi.ru

Тема: API коммерческой недвижимости и разрешение на публичную публикацию InvestScan

Здравствуйте.

Разрабатываем InvestScan — публичный каталог готового арендного бизнеса: https://maxrubtsoff.github.io/InvestScan/ . Источники и происхождение данных показываются в карточках.

Нужен доступ к объявлениям о продаже коммерческой недвижимости Татарстана и соседних населённых пунктов, включая предложения с Авито, ЦИАН и Домклика. Контактные телефоны и данные продавцов не нужны.

Просим уточнить:

1. Можно ли получить тестовую выборку реальных коммерческих объявлений с описаниями, ценами, ссылками, координатами и фактическими датами получения/проверки источника?
2. Разрешена ли публикация отобранных карточек и вычисленных арендных показателей на GitHub Pages, включая открытый JSON каталога, с указанием первоисточников и поставщика? Понимаем, что по пункту 6.1.4 оферты требуется отдельное письменное согласие.
3. Какие условия лицензии и стоимость предусматривают такой вариант использования? Можно ли публиковать превью фотографий либо только ссылку на оригинал?
4. Каков фактический охват коммерческих предложений по Татарстану и окрестностям, и различаются ли дата публикации, обновления и последнего подтверждения объявления площадкой?

Это запрос информации об условиях, без согласия на подключение или оплату услуг.
