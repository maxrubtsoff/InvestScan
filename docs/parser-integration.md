## Avito: Duff89/parser_avito

Изучен коммит `91a5399f79bf035d3eb919d66ada00545571c2f1`. Репозиторий содержит DTO, экспорт XLSX, HTTP-клиент на curl_cffi, получение cookies и смену прокси. Его код не копировался, зависимости и запускаемые файлы не установлены. Отдельная лицензия на код в проверенном дереве не обнаружена.

Реализовано независимое чтение его штатных экспортов: `imports/avito/*.xlsx`, `.csv`, `.json` (массив items). Поддержаны русские заголовки `Название`, `Цена`, `URL`, `Описание`, `Адрес`, `Адрес пользователя` и поля JSON `title`, `priceDetailed`, `urlPath`, `coords`. Контакты, cookies и идентификаторы продавцов не импортируются. В базу попадают только признаки арендной модели; месячная аренда берётся из явного МАП.

Обычный HTTP-запрос к публичной коммерческой категории Татарстана вернул HTTP 200 с заголовком `Site Unavailable`, а не объявления. Этот ответ считается блокировкой/недоступностью, не нулём объявлений. Прокси, чужие cookies, fingerprint spoofing и обходы не включены. Живой сбор Авито не заявляется работающим.

## Cian: lenarsaitov/cianparser

Изучен коммит `236352a200b08b27c24d14b18939b4c34691cbb2`, MIT. Публичные методы библиотеки рассчитаны на квартиры, загородные объекты и новостройки, а не нужную коммерческую категорию. Используется cloudscraper; библиотека целиком не устанавливалась и не запускалась.

Написан независимый коммерческий адаптер `parsers/cian.py`: обычный HTTP, публичная страница готового бизнеса по Татарстану, чтение опубликованного initialState в HTML через JSONDecoder без выполнения JavaScript и без обращения к внутренним API. Пагинация — только по ссылкам страницы, до 12 страниц за проход. Объекты из всей республики сохраняются, затем применяется географический фильтр.

Фильтруются бизнесы без признаков арендной модели, субаренда и переуступка. Поле monthlyIncome не используется: оно может обозначать прибыль действующего бизнеса, а не аренду. Годовой арендный поток не принимается за месячный. Цена сохраняется только в рублях; tracking query удаляется из ссылки. Неопределённый/скрытый адрес не получает координат здания. Публичные фото показываются как ссылки на CDN с атрибуцией.

Первичная проверка: обычная страница доступна, HTTP 200; коммерческое состояние действительно извлечено. Доступность с GitHub Actions проверяется отдельно при запуске. При CAPTCHA, 401, 403, 429 источник прекращает запросы, существующий каталог сохраняется. Правила Циан требуют отдельного разрешения на автоматизированный сбор: https://www.cian.ru/legal-documents/pravila_polzovaniya_sajtom_cian_853 . Публичная доступность не означает предоставление такого разрешения или права перепубликации произвольных материалов.

## Статусы

`ok` — источник действительно отдал и распарсил объявления; `blocked` — ограниченный доступ или защитная проверка; `error` — сеть/структура/валидация; count — фактически обработанные записи. При частичном сборе до ошибки записи сохраняются, источник не обозначается успешным. Один источник не останавливает остальные.

При push кода обновляются новые адаптеры avito/cian/domclick; сохранённые записи АРР остаются. Почасовой и ручной запуск обновляют все источники. `INVESTSCAN_SOURCES=all` — полный проход.
