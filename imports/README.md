# Импорт

Добавляйте только данные, на использование которых у вас есть права, без контактов продавцов и секретов.
Формат файла `*.json` — массив объектов. `title` и `sources: [{name, url}]` обязательны.
`name`: Авито, ЦИАН или Домклик. `price`, `area`, `monthly_rent` — числа в рублях/м²;
неизвестные поля — null. Координаты `[широта, долгота]` требуют `coordinate_source` и
`geo_accuracy: building | parcel | street`. Для подтверждения: `active_tenant`,
`payments_confirmed`, `contract` должны быть true; нужна `verification_evidence`.
Не публикуйте персональные данные документов — укажите обезличенное основание проверки.
См. `analyzer/validation.py` для полной схемы.

## Нативные форматы

- `imports/avito/*.xlsx`, `.csv`, `.json`: поля Duff89 (`Название`, `Цена`, `URL`, `Описание`, адрес) или `items[]` с `title`, `urlPath`, `priceDetailed`, `geo`, `images`. Цена за м² и иностранная валюта не считаются общей ценой помещения в рублях. Числовая колонка `Цена` задаётся в рублях.
- `imports/domclick/*.json`: массив или `result.items`, `items`, `offers`; поля `dealType`, `offerType`, `category`, `objectInfo`, `address.displayName`, `path`, `description`. Для объекта `price` нужна явная рублёвая `currency`.
- `imports/domclick/*.csv` и JSON модели Offer: `type: Sale office` (или другой коммерческий тип), `listing_url`, `address`, `area`, `floor`, `price`, `description`. Числовой `price` в этом формате задаётся в рублях, `area` — в м².

`source_fetched_at` — фактическое время получения исходных данных в ISO 8601 с часовым поясом, если известно. Если времени нет, оставьте null: оно не заменяется датой файла или запуска. Время более чем на 10 минут впереди текущего не принимается. Повторный импорт не является новой проверкой объявления. Более старый/недатированный файл не перезаписывает более свежее наблюдение по той же ссылке. Импорт маркируется отдельно от получения публичной страницы.

Из экспорта копируются только поля объекта; cookies, API-ключи, заголовки запросов и контактные поля не публикуются. Синтетические тестовые фикстуры не находятся в `imports/` и не попадают в каталог.
