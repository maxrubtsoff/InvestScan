# InvestScan

[Сайт](https://maxrubtsoff.github.io/InvestScan/) · [Сбор и публикация](https://github.com/maxrubtsoff/InvestScan/actions/workflows/update.yml)

Статический каталог готового арендного бизнеса: Казань и окрестности. Python 3.11+, SQLite, JSON, HTML/CSS/JS. Постоянный сервер и платные API не нужны.

## Что реализовано

- Бюджет 12 млн ₽ и радиус 100 км по умолчанию; 30/50/100/150/200 км и без ограничения. Более дорогие объекты сохраняются; для их поиска измените максимальную цену.
- Статистика относится к выбранной географии и бюджету. Глобальная база вынесена в пояснение охвата. Неопределённые адреса скрыты по умолчанию; в ограниченном радиусе в очередь проверки попадают только адреса с признаками региона поиска, без подстановки координат. Объекты из Самары и других явно посторонних регионов не подмешиваются в локальную очередь.
- Фильтры цены, площади, населённого пункта, района, арендатора, договора, индексации, доходности, окупаемости и статуса; сортировка и географическая схема.
- Независимые сборщики, проверка robots.txt с паузами, сохранение прежнего каталога при сбоях, консервативная дедупликация, история цены и условий в SQLite.
- Валовые показатели, чистые показатели только при полном наборе расходов, три явно условных сценария, объяснимый скоринг 0–100.
- Ежедневный GitHub Actions (`17 3 * * *`, 06:17 МСК), ручной запуск, тесты, коммит данных и публикация GitHub Pages. Страница получает JSON при открытии, по кнопке «Проверить обновление» и раз в сутки, если остаётся открытой. Эта кнопка не запускает парсеры.

## Данные и ограничения

### АРР — работающий автоматический источник

Сборщик читает общероссийскую [публичную витрину](https://broker.arrpro.ru/arendniy-biznes/) и все доступные страницы (защитный предел — 80), открываемых её публичной пагинацией. Проход охватывает доступную пагинацию этой витрины, не весь рынок. Число пройденных страниц и записей публикуется в coverage. Поиск не ограничивается Казанью: загружаются и другие населённые пункты; географический отбор происходит по координатам. Данные о цене и месячной аренде — заявления источника, а не проверенные платежи.

[Правовая информация АРР](https://arrpro.ru/o-kompanii/Правовая_информация.pdf) требует ссылку при использовании материалов; она сохраняется в каждой карточке. Изображения принадлежат компании. В карточках используются HTTPS-превью с публичного CDN источника со ссылкой на оригинал и атрибуцией; изображения не скачиваются в репозиторий. Недоступное фото заменяется короткой ссылкой на источник. Контакты и полные описания автоматически не перепубликуются. При изменении правил или блокировке сбор останавливается. Сборщик не обходит CAPTCHA и авторизацию. Не является юридическим заключением о правах на произвольные выгрузки.

### Авито / ЦИАН / Домклик

Повторное испытание 16.11.2026: локально получены все 162 объявления коммерческой выдачи ЦИАН, отобраны 37 кандидатов и сохранены с фактическими датами. В GitHub Actions источник снова предъявил защитную страницу; ежедневный сбор не подтверждён. У пяти дополнительных сторонних парсеров проверены функции извлечения на настоящих ответах. [Результаты испытаний 11 репозиториев](docs/parser-trials-2026-11-16.md).

Предусмотрены отдельные адаптеры разрешённых экспортов. Авито читает распознанное MFE-состояние публичного HTML и XLSX/CSV/JSON Duff89; Домклик — нативные JSON/CSV и экспериментальное состояние HTML; ЦИАН — коммерческое состояние публичной страницы. **Живой регулярный сбор этих трёх площадок не подтверждён**: Авито возвращал недоступность/404, ЦИАН и Домклик — защитные проверки. Форматные тесты и статические импорты не считаются подключением живого источника. API собственных объявлений не считается API поиска всего рынка. Платные каналы и новые аккаунты не подключаются без согласования; [текущие препятствия и проверенные варианты](docs/source-goal.md).

Импорт и живой ответ учитываются раздельно (`imported_count` / `live_count`); неверная запись не останавливает остальные. Старый или недатированный импорт не откатывает более свежие факты, повтор файла не обновляет наблюдение. При утрате SQLite опубликованный JSON восстанавливается без подмены дат источника. Подробнее: [форматы импорта](imports/README.md).

Наблюдение из будущего более чем на 10 минут отклоняется как ошибочное. При объединении площадок канонические факты остаются у первой ссылки: повторное обновление второй площадки не заменяет их молча. Актуальные цены каждой площадки сохраняются в `price_claims`, расхождения блокируют финансовый расчёт и учитываются в бюджете. После совпадения актуальных цен конфликт снимается. История указывает источник изменения.

### РБН — независимая публичная витрина

`parsers/rbn.py` читает [каталог офиса Казани](https://kazan.rbnpro.ru/rents/show_all) и карточки, в том числе Зеленодольск и другие муниципалитеты, которые включил источник. На 16.11.2026 robots.txt разрешает чтение. Между запросами минимум 10 секунд; следуем только опубликованным ссылкам, предел 20 страниц. Это отдельный источник, не прямой сбор Авито/Циан/Домклика и не весь рынок. Бюджет не ограничивает сбор. Карточки без признаков аренды и предложения будущей сдачи отбрасываются. Заявленная окупаемость не превращается в выдуманную месячную аренду; неизвестные платежи и документы остаются неизвестными. Фото — ссылка на публичное превью источника с атрибуцией, без копирования в репозиторий.

Для адресов РБН в ежедневном workflow включён Photon / OpenStreetMap: максимум четыре новых адреса за запуск, один поток, пауза 15 секунд, постоянный кэш, остановка сетевых запросов после ошибки. [Условия публичного сервера](https://github.com/komoot/photon#demo-server): допускается разумное использование без гарантии доступности. Для координат обязаны совпасть город, улица, тип улицы и полный номер дома; центр города или соседний дом не подходят. Название магазина в геокодере никогда не становится арендатором. Атрибуция OSM присутствует на карте и в происхождении координат. Отключение: `INVESTSCAN_PHOTON=0`; замена сервера — `PHOTON_URL`. Nominatim по умолчанию по-прежнему выключен.

### География

Центр: 55.796127, 49.106414. Haversine, километры по прямой. Никаких выдуманных координат. Без надёжных координат объект остаётся в группе «Местоположение не определено» и не попадает в географический рейтинг. Географическая схема — проекция координат относительно центра, не дорожная карта.

По умолчанию используются координаты маркера на публичной карте объекта АРР (до 6 новых карточек за запуск, с кэшем). Точность — утверждение источника, не кадастровое подтверждение. Населённый пункт из витрины может обозначать региональный офис; полный адрес и расстояние приоритетнее.

Опциональное геокодирование выключено по умолчанию. Для осознанного включения после ознакомления с политикой — `INVESTSCAN_GEOCODE=1`. Геокодирование: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL; Nominatim. **Важны [правила сервиса](https://operations.osmfoundation.org/policies/nominatim/)**: периодическое использование ограничено 4 запросами/минуту, один поток/машина, обязательные User-Agent, атрибуция и постоянный кэш. Здесь не более 10 новых адресов за запуск, пауза 15.1 сек., повторные адреса берутся из кэша; при ошибке запросы прекращаются. Для отключения — `INVESTSCAN_GEOCODE=0`; альтернативный совместимый сервис — переменная `GEOCODER_URL`. Не включайте несколько параллельных установок с публичным Nominatim. Геокодирование может быть недоступно или ошибаться: совпадение центра города не признаётся координатами помещения. Точность `building` означает результат геокодера с номером дома, не кадастровую проверку.

Нельзя гарантировать полноту охвата поселений, актуальность предложения или точность адреса продавца. Снятые объявления не удаляются автоматически: сверяйте `last_seen` и ссылку источника. Дата публикации остаётся null, если источник её не предоставляет.

## Проверка ГАБ и рисков

`confirmed` требует `active_tenant=true`, `payments_confirmed=true`, `contract=true`, положительную аренду и `verification_evidence` — обезличенное документированное основание. Одно упоминание «ГАБ», бренда или МАП недостаточно. Автоматически полученные объявления АРР имеют `review`. Подтверждённые платежи не гарантируют будущие.

Неизвестные характеристики — null, не false. True/false/null отображаются как «Подтверждено» / «Не подтверждено» / «Нет информации». Показатели надёжности, расторжения, срока работы, состояния и юридических рисков не придумываются.

Рейтинг — версия 1 в `analyzer/scoring.py`: доходность 15, окупаемость 15, подтверждение аренды 15, договор 10, индексация 5, локация 5, расстояние 10, состояние 5, полнота 10, цена относительно рынка 10. Последний фактор пока 0: нет проверенных аналогов. Без подтверждения ГАБ рейтинг ограничен 39. Для каждого фактора публикуется причина. Это эвристика отбора, не оценка стоимости или инвестиционная рекомендация.

## Финансы

Годовая аренда = МАП × 12. Валовая доходность = годовая аренда / цена × 100. Простая окупаемость = цена / годовая аренда. Для чистых значений нужны все `annual_costs`: tax, utilities, maintenance, insurance, management, commissions, плюс transaction_costs и vacancy_months. Известный ноль указывается явно.

Сценарии: простой 0/1/2 мес., резерв неизвестных расходов 5/10/15% валовой аренды и расходы на сделку 0/2/3% цены. Известные расходы и простой заменяют допущения; неизвестный остаток оценивается общим резервом. Сценарии без полного набора расходов не называются фактической чистой доходностью. Индексация и рост цены в прогноз не включены.

## Автоматизация и хранение

`.github/workflows/update.yml` собирает данные раз в сутки и по явному ручному запуску. Изменение кода запускает тесты и публикацию без запросов к площадкам. GitHub может задерживать расписание; в неактивном публичном репозитории scheduled workflows могут отключаться по правилам GitHub. Workflow имеет contents:write, pages:write, id-token:write, concurrency и timeout; Pages публикует только index.html, css, js, listings.json. Репозиторий публичный: не добавляйте приватные документы, контакты или ключи в imports/ или data/.

При ручном запуске поле `sources` позволяет проверить один источник. Состояние и число записей остальных источников сохраняются вместе с `checked_this_run=false`: пропуск источника не превращает прежнюю блокировку в успешное обновление.

Если повторное чтение РБН показывает будущую сдачу или условную окупаемость «при заполнении», запись помечается `catalog_eligible=false`: история остаётся в SQLite, публичная выдача её не показывает. Это отличается от недоступности источника: при сетевой ошибке прежние записи не исключаются. Противоречивые цены сохраняются в `price_claims` и показываются диапазоном с предупреждением; для фильтра бюджета учитывается и верхняя цена, доходность и окупаемость не рассчитываются до уточнения. Фильтр заявленного арендатора не требует известного МАП и не означает документального подтверждения.

SQLite и кэш коммитятся вместе с JSON; не зависят от временного Actions cache. Ошибка одного источника отражается в `sources` и не удаляет существующие объявления. Первое обнаружение, последнее наблюдение и история условий сохраняются. Дубликаты объединяются по общей ссылке, а между площадками — по совпадению адреса/поселения, площади с точностью 0.1 м² и координат в пределах 30 м. Возможные ложные совпадения требуют проверки; разные помещения одного здания должны иметь разные адреса/номера. Конфликтующие цены сохраняются в source_observations, не заменяются молча.

## Структура

`parsers/` — источники; `analyzer/` — проверки, география, расчёты и рейтинг; `storage/` — SQLite; `scripts/` — обновление; `tests/` — проверки; `data/` — опубликованный JSON и история; `js/` и `css/` — интерфейс.

## Граница готовности

Работает автоматический сбор публичной выборки АРР. Полный охват рынка, автоматический успешный сбор Авито/Домклик и независимая документальная проверка ГАБ не заявляются реализованными. Пустой основной каталог при строгих фильтрах может быть корректным результатом; расширьте радиус/бюджет или изучите группу неопределённых адресов.

## Карта и фильтры

Максимальная цена и площадь соблюдаются во всех режимах. Отдельных кнопок для превышения бюджета нет; для другого бюджета измените фильтр. Карта на собственном JavaScript-коде и тайлах OpenStreetMap открывается из каталога и показывает ту же выборку с ценами, адресами и ссылками на источники. Нет координат — нет маркера. Подложка загружается по запросу пользователя без предзагрузки тайлов, с атрибуцией и обычным браузерным кэшированием, согласно https://operations.osmfoundation.org/policies/tiles/. Внешних JavaScript-библиотек карты нет. Координаты переводятся в Web Mercator, тайлы загружаются только в видимой области после открытия карты. Поддержаны перенос, масштабирование, ценовые метки и карточки объявлений. При недоступности подложки список и метки остаются доступны.

## Интеграции предложенных парсеров

Для обработки уже полученного датированного снимка без повторных запросов есть ручной параметр workflow `import_only=true` (`INVESTSCAN_IMPORTS_ONLY=1` локально). Он обновляет SQLite/JSON, не обращается к площадкам и геокодерам, сохраняет известные ограничения источников и исходные даты. Плановый ежедневный запуск использует обычный сбор, этот параметр по умолчанию выключен.

Актуальный технический разбор и ограничения: [docs/parser-integration.md](docs/parser-integration.md). Коммерческий сбор Циан реализован отдельным адаптером публичной страницы Татарстана. Авито и Домклик проверяются обычными HTTP-запросами и честно сообщают недоступность; обходы не используются. Для штатных XLSX/CSV/JSON экспортов Duff89 добавлено автоматическое чтение `imports/avito/`.

## Обработка без ИИ

В рабочем приложении нет LLM/OpenAI-запросов. Python-сборщики извлекают поля по проверяемым правилам, финансовый модуль выполняет формулы, интерфейс использует шаблоны текста. ИИ применяется только при разработке кода, а не при ежедневном сборе или анализе объявлений. Плановый сбор: ежедневно 06:17 МСК (03:17 UTC), возможна задержка GitHub. Нажатие «Проверить обновление» читает опубликованный JSON и не обращается к площадкам.
