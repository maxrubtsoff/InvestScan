# InvestScan

[Сайт](https://maxrubtsoff.github.io/InvestScan/) · [Сбор и публикация](https://github.com/maxrubtsoff/InvestScan/actions/workflows/update.yml)

Статический каталог готового арендного бизнеса: Казань и окрестности. Python 3.11+, SQLite, JSON, HTML/CSS/JS. Постоянный сервер и платные API не нужны.

## Что реализовано

- Бюджет 12 млн ₽ и радиус 100 км по умолчанию; 30/50/100/150/200 км и без ограничения. Более дорогие объекты сохраняются и доступны отдельным переключателем.
- Статистика относится к выбранной географии и бюджету. Глобальная база вынесена в пояснение охвата. Неопределённые адреса скрыты по умолчанию; в ограниченном радиусе в очередь проверки попадают только адреса с признаками региона поиска, без подстановки координат. Объекты из Самары и других явно посторонних регионов не подмешиваются в локальную очередь.
- Фильтры цены, площади, населённого пункта, района, арендатора, договора, индексации, доходности, окупаемости и статуса; сортировка и географическая схема.
- Независимые сборщики, проверка robots.txt с паузами, сохранение прежнего каталога при сбоях, консервативная дедупликация, история цены и условий в SQLite.
- Валовые показатели, чистые показатели только при полном наборе расходов, три явно условных сценария, объяснимый скоринг 0–100.
- Почасовой GitHub Actions (`17 * * * *`), ручной запуск, тесты, коммит данных и публикация GitHub Pages. Страница перечитывает JSON каждые 5 минут.

## Данные и ограничения

### АРР — работающий автоматический источник

Сборщик читает общероссийскую [публичную витрину](https://broker.arrpro.ru/arendniy-biznes/) и все доступные страницы (защитный предел — 80), открываемых её публичной пагинацией. Проход охватывает доступную пагинацию этой витрины, не весь рынок. Число пройденных страниц и записей публикуется в coverage. Поиск не ограничивается Казанью: загружаются и другие населённые пункты; географический отбор происходит по координатам. Данные о цене и месячной аренде — заявления источника, а не проверенные платежи.

[Правовая информация АРР](https://arrpro.ru/o-kompanii/Правовая_информация.pdf) требует ссылку при использовании материалов; она сохраняется в каждой карточке. Изображения принадлежат компании. В карточках используются HTTPS-превью с публичного CDN источника со ссылкой на оригинал и атрибуцией; изображения не скачиваются в репозиторий. Недоступное фото заменяется короткой ссылкой на источник. Контакты и полные описания автоматически не перепубликуются. При изменении правил или блокировке сбор останавливается. Сборщик не обходит CAPTCHA и авторизацию. Не является юридическим заключением о правах на произвольные выгрузки.

### Авито / ЦИАН / Домклик

Предусмотрены отдельные адаптеры разрешённых экспортов из `imports/*.json`. **Автоматический поиск чужих объявлений этих трёх площадок не подключён**: разрешённый общедоступный discovery API не установлен. API выгрузки собственных объявлений не считается API поиска всего рынка. Нет скрытых endpoints, купленных баз, чужих cookies или обхода ограничений. Подключение официального источника требует соответствующего разрешения; сборщики не имитируют результаты. [ЦИАН API](https://public-api.cian.ru/docs/latest).

### География

Центр: 55.796127, 49.106414. Haversine, километры по прямой. Никаких выдуманных координат. Без надёжных координат объект остаётся в группе «Местоположение не определено» и не попадает в географический рейтинг. Географическая схема — проекция координат относительно центра, не дорожная карта.

По умолчанию используются координаты маркера на публичной карте объекта АРР (до 6 новых карточек за запуск, с кэшем). Точность — утверждение источника, не кадастровое подтверждение. Населённый пункт из витрины может обозначать региональный офис; полный адрес и расстояние приоритетнее.

Опциональное геокодирование выключено по умолчанию. Для осознанного включения после ознакомления с политикой — `INVESTSCAN_GEOCODE=1`. Геокодирование: © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL; Nominatim. **Важны [правила сервиса](https://operations.osmfoundation.org/policies/nominatim/)**: периодическое использование ограничено 4 запросами/минуту, один поток/машина, обязательные User-Agent, атрибуция и постоянный кэш. Здесь не более 10 новых адресов за запуск, пауза 15.1 сек., повторные адреса берутся из кэша; при ошибке запросы прекращаются. Для отключения — `INVESTSCAN_GEOCODE=0`; альтернативный совместимый сервис — переменная `GEOCODER_URL`. Не включайте несколько параллельных установок с публичным Nominatim. Геокодирование может быть недоступно или ошибаться: совпадение центра города не признаётся координатами помещения. Точность `building` означает результат геокодера с номером дома, не кадастровую проверку.

Нельзя гарантировать полноту охвата поселений, актуальность предложения или точность адреса продавца. Снятые объявления не удаляются автоматически: сверяйте `last_seen` и ссылку источника. Дата публикации остаётся null, если источник её не предоставляет.

## Проверка ГАБ и рисков

`confirmed` требует `active_tenant=true`, `payments_confirmed=true`, `contract=true`, положительную аренду и `verification_evidence` — обезличенное документированное основание. Одно упоминание «ГАБ», бренда или МАП недостаточно. Автоматически полученные объявления АРР имеют `review`. Подтверждённые платежи не гарантируют будущие.

Неизвестные характеристики — null, не false. True/false/null отображаются как «Подтверждено» / «Не подтверждено» / «Нет информации». Показатели надёжности, расторжения, срока работы, состояния и юридических рисков не придумываются.

Рейтинг — версия 1 в `analyzer/scoring.py`: доходность 15, окупаемость 15, подтверждение аренды 15, договор 10, индексация 5, локация 5, расстояние 10, состояние 5, полнота 10, цена относительно рынка 10. Последний фактор пока 0: нет проверенных аналогов. Без подтверждения ГАБ рейтинг ограничен 39. Для каждого фактора публикуется причина. Это эвристика отбора, не оценка стоимости или инвестиционная рекомендация.

## Финансы

Годовая аренда = МАП × 12. Валовая доходность = годовая аренда / цена × 100. Простая окупаемость = цена / годовая аренда. Для чистых значений нужны все `annual_costs`: tax, utilities, maintenance, insurance, management, commissions, плюс transaction_costs и vacancy_months. Известный ноль указывается явно.

Сценарии: простой 0/1/2 мес., резерв неизвестных расходов 5/10/15% валовой аренды и расходы на сделку 0/2/3% цены. Известные расходы и простой заменяют допущения; неизвестный остаток оценивается общим резервом. Сценарии без полного набора расходов не называются фактической чистой доходностью. Индексация и рост цены в прогноз не включены.

## Разработка

```sh
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python -m pytest -q
node --test tests/frontend.test.js
python scripts/update_catalog.py
python -m http.server 8000
```

Открыть http://localhost:8000. Импорт: [imports/README.md](imports/README.md). Тестовые данные находятся только в тестах и не публикуются как объявления.

## Автоматизация и хранение

`.github/workflows/update.yml` запускается ежечасно, вручную и при изменениях кода. GitHub может задерживать расписание; в неактивном публичном репозитории scheduled workflows могут отключаться по правилам GitHub. Workflow имеет contents:write, pages:write, id-token:write, concurrency и timeout; Pages публикует только index.html, css, js, listings.json. Репозиторий публичный: не добавляйте приватные документы, контакты или ключи в imports/ или data/.

SQLite и кэш коммитятся вместе с JSON; не зависят от временного Actions cache. Ошибка одного источника отражается в `sources` и не удаляет существующие объявления. Первое обнаружение, последнее наблюдение и история условий сохраняются. Дубликаты объединяются по общей ссылке, а между площадками — по совпадению адреса/поселения, площади с точностью 0.1 м² и координат в пределах 30 м. Возможные ложные совпадения требуют проверки; разные помещения одного здания должны иметь разные адреса/номера. Конфликтующие цены сохраняются в source_observations, не заменяются молча.

## Структура

`parsers/` — источники; `analyzer/` — проверки, география, расчёты и рейтинг; `storage/` — SQLite; `scripts/` — обновление; `tests/` — проверки; `data/` — опубликованный JSON и история; `js/` и `css/` — интерфейс.

## Граница готовности

Работает автоматический сбор публичной выборки АРР. Полный охват рынка, Авито/ЦИАН/Домклик и независимая документальная проверка ГАБ не заявляются реализованными. Пустой основной каталог при строгих фильтрах может быть корректным результатом; расширьте радиус/бюджет или изучите группу неопределённых адресов.

## Карта и фильтры

Максимальная цена и площадь соблюдаются во всех режимах. Отдельных кнопок для превышения бюджета нет; для другого бюджета измените фильтр. Карта Leaflet 1.9.4 / OpenStreetMap открывается из каталога и показывает ту же выборку с ценами, адресами и ссылками на источники. Нет координат — нет маркера. Подложка загружается по запросу пользователя без предзагрузки тайлов, с атрибуцией и обычным браузерным кэшированием, согласно https://operations.osmfoundation.org/policies/tiles/. Стили и скрипт Leaflet загружаются с unpkg.com; если сервис недоступен, список объявлений остаётся доступен.
